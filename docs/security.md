# Security notes

- **SSH is restricted** to `ssh_allowed_cidr` for the GitLab server and
  Runner Manager. Workers accept SSH only from the Runner Manager's
  security group — never open to `0.0.0.0/0`. Set `ssh_allowed_cidr` to
  your real IP (`/32`) before the first apply.
- **IAM is split two ways**: the Runner Manager role can only describe/scale
  the tagged worker ASG and describe/tag EC2 instances — it cannot touch
  arbitrary AWS resources. The worker role ships empty; add permissions to
  `modules/iam` only as specific CI jobs need them.
- **No secrets in Terraform.** The GitLab root password is generated by
  GitLab itself on first boot (`/etc/gitlab/initial_root_password`, valid
  24h). The runner registration token is fetched out-of-band at
  registration time, not baked into user-data or committed to this repo.
- **EBS volumes are encrypted** by default on both the GitLab server and
  workers.
- Before this repo goes on GitHub: double check `terraform.tfvars` is
  gitignored (it is, by default) so `ssh_allowed_cidr` and any future
  secrets never get committed.
